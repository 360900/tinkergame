# Migrating to TinkerGame

TinkerGame is a breaking rename of SteamTinkerLaunch. The old executable,
installation paths, cache paths, and configuration paths are not supported.

## Before Installing

Close Steam and back up the old user data:

```sh
cp -a "${XDG_CONFIG_HOME:-$HOME/.config}/steamtinkerlaunch" \
  "${XDG_CONFIG_HOME:-$HOME/.config}/steamtinkerlaunch.backup"
```

If you used custom cache or data locations, back up these directories too:

```text
~/.cache/steamtinkerlaunch
~/.local/share/steamtinkerlaunch
/dev/shm/steamtinkerlaunch
```

## Copy Configuration

Install TinkerGame, run it once, then copy the old configuration into the new
location:

```sh
cp -a "${XDG_CONFIG_HOME:-$HOME/.config}/steamtinkerlaunch/." \
  "${XDG_CONFIG_HOME:-$HOME/.config}/tinkergame/"
```

Configuration files generated by older versions may contain old template file
names. Rename those files after copying if needed:

```sh
find "${XDG_CONFIG_HOME:-$HOME/.config}/tinkergame" \
  -depth -name '*SteamTinkerLaunch*' \
  -exec sh -c 'new=$(printf "%s" "$1" | sed "s/SteamTinkerLaunch/TinkerGame/g"); mv "$1" "$new"' _ {} \;
```

Review custom configuration values before launching a game. In particular,
check custom commands, compatibility-tool paths, and scripts that explicitly
call `steamtinkerlaunch`.

## Re-register With Steam

Remove the old compatibility-tool entry and register TinkerGame again:

```sh
steamtinkerlaunch compat del
tinkergame compat add
```

If the old installation was managed by ProtonUp-Qt, ProtonPlus, or a package
manager, remove the old entry there and install TinkerGame through the same
tool once packaging is available.

## Cleanup

After confirming that games and settings work, the old data can be removed:

```sh
rm -rf "${XDG_CONFIG_HOME:-$HOME/.config}/steamtinkerlaunch"
rm -rf "${XDG_CACHE_HOME:-$HOME/.cache}/steamtinkerlaunch"
rm -rf "${XDG_DATA_HOME:-$HOME/.local/share}/steamtinkerlaunch"
rm -rf /dev/shm/steamtinkerlaunch
```

Do not remove the backup until all per-game settings and downloaded tools have
been verified.
